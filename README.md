# 正方形の周上を動く単位球面の通過部分 ― 3D可視化Webアプリ

空間内の1辺の長さ1の正方形 ABCD を考えます。点 P が正方形の辺上を1周するとき、P を中心とする半径1の球面が通過する部分を、ブラウザ上で3D表示するWebアプリです。

## 特長

- 通過部分の立体をマウスで回転・拡大縮小しながら見られます。
- 点 P と球面が周上を動くアニメーションを再生できます。
- 「成長」モードでは、P が動くにつれて通過部分が広がる様子を確認できます。
- 立体を平面で切って、内部の空洞を見ることができます。
- 水平断面 $z=t$ の形を2D図で表示し、現在の区間を数式で示します。
- 体積の概算値を表示します(格子点を数える方法)。
- 数式は KaTeX で表示するので、$\sqrt{\ }$ や分数が正しく組まれます。

## 動かし方

### 1. ファイルを直接開く

`index.html` をダブルクリックしてブラウザで開くだけで動きます。インストールは不要です。

### 2. ローカルサーバーで開く(直接開いて動かない場合)

ブラウザの設定によっては、ファイルを直接開くと動かないことがあります。その場合は次のようにローカルサーバーを起動してください。

```bash
# Python 3 がある場合
python -m http.server 8000
```

起動したら、ブラウザで http://localhost:8000/ を開きます。

### 3. Web上に公開する

`index.html` 1つで完結しているので、GitHub Pages などの静的ホスティングにそのまま置けば公開できます。

## 動作環境

- インターネット接続が必要です(Three.js と KaTeX をCDNから読み込むため)。
- import map に対応したブラウザが必要です(Chrome / Edge 89以降、Firefox 108以降、Safari 16.4以降)。
- WebGL が使える環境が必要です。

## 画面の操作

| 項目 | 内容 |
|---|---|
| 表示モード | 「完成形」は1周後の通過部分を、「成長」は P が通った分だけの通過部分を表示します。 |
| 点Pの位置 $s$ | A→B→C→D→A を $0 \sim 4$ で指定します。「▶ 再生」で自動的に1周します。 |
| 断面の高さ $z$ | 2D断面図と、3D内の半透明の平面の高さを変えます。 |
| 切断表示 | $y=0.5$ または $x=0.5$ で半分に切るか、断面より上を取り除きます。切り口から見える内側の面は橙色で表示されます。 |
| 不透明度 | 立体を半透明にします。 |
| 球面 / 断面の平面 | 球面(赤い網)と断面の平面の表示・非表示を切り替えます。 |
| 解像度 | 格子の細かさです。大きくすると形がなめらかになり、体積の概算も正確になりますが、計算に時間がかかります。 |

3D画面では、ドラッグで回転、ホイールで拡大縮小、右ドラッグで平行移動ができます。

## 数学的な背景

座標を $A(0,0,0),\ B(1,0,0),\ C(1,1,0),\ D(0,1,0)$ とします。

点 $X$ から周上の点 $P$ までの距離の最小値を $d_{\min}(X)$、最大値を $d_{\max}(X)$ とします。正方形の周はつながった曲線なので、$|XP|$ は $d_{\min}$ から $d_{\max}$ までのすべての値をとります。したがって、$X$ が通過部分に入る条件は次の式です。

$$
d_{\min}(X) \le 1 \le d_{\max}(X)
$$

- $d_{\min} \le 1$ は、$X$ が周を芯とする半径1のチューブの中にあることを表します。
- 周上で $X$ から最も遠い点は必ず頂点です。そのため $d_{\max} \ge 1$ は、「4頂点すべてから距離1未満」という領域を除くことと同じです。除かれる部分は、中心 $\left(\tfrac12,\tfrac12,0\right)$ のまわりの空洞で、$|z| < \tfrac{1}{\sqrt{2}}$ の範囲にあります。

水平面 $z=t$ で切った断面の形は次のとおりです($r=\sqrt{1-t^2}$)。

| 高さ | 断面の形 |
|---|---|
| $\lvert t\rvert < \frac{1}{\sqrt{2}}$ | 角の丸い正方形から、4つの円(中心は各頂点、半径 $r$)の共通部分を除いた形 |
| $\frac{1}{\sqrt{2}} \le \lvert t\rvert \le \frac{\sqrt{3}}{2}$ | 穴のない、角の丸い正方形 |
| $\frac{\sqrt{3}}{2} < \lvert t\rvert \le 1$ | 1辺 $1-2r$ の正方形の穴があいた枠 |

## 実装の概要

- 陰関数 $F(X)=\max\left(d_{\min}-1,\ 1-d_{\max}\right)$ を3D格子上で計算します。$F \le 0$ の部分が通過部分です。
- 境界面 $F=0$ を **Surface Nets** 法で三角形メッシュにし、Three.js で描画しています。
- 外側の面と内側の面を別々のマテリアル(青 / 橙)で描くことで、切断したときに内部の空洞がわかるようにしています。
- 「成長」モードでは、A から現在の P までの経路だけを使って $d_{\min}$ と $d_{\max}$ を計算し直します。
- 断面図は Canvas 2D 上でピクセルごとに色分けしています。青が通過部分、橙が空洞です。
- 体積は、格子点のうち $F<0$ を満たすものの数に格子1つ分の体積をかけた概算値です。

## 注意事項

- 表示される体積は格子による概算値です。解像度が低いと誤差が大きくなります。
- 解像度を130にすると、端末によっては動作が重くなることがあります。
- 日本語が文字化けする場合は、`index.html` を UTF-8 で保存し直してください。
